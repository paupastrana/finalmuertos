Máscara de Día de Muertos - Malla 3D

Filtro de cámara web que pone una máscara de Día de Muertos sobre tu cara. La imagen se adapta a la malla facial (468 puntos de MediaPipe Face Mesh), así que se deforma cuando giras, inclinas la cabeza o abres la boca.

Cómo usarlo
Abre index.html desde un servidor local (por ejemplo, la extensión Live Server de VS Code). La cámara no funciona abriendo el archivo directo.
Acepta el permiso de la cámara.
Mira de frente unos segundos mientras se calibra la máscara.
Controles
Recalibrar (botón o tecla R): vuelve a ajustar la máscara.
Tecla M: muestra u oculta la malla (para depurar).
Archivos
index.html: la página.
script.js: lógica de la máscara y la cámara.
mascara.png: imagen de la máscara.
mascara_textura.png: textura de la máscara.
Tecnologías

HTML, JavaScript y MediaPipe Face Mesh.
